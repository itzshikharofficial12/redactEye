# Browser Utilities Package (`packages/browser-utils`)

This package contains browser-specific helper functions, DOM manipulation tools, viewport coordinate calculators, and low-level browser interaction utilities.

## Ownership
- **Primary Owner:** Person 1 — Browser / Extension

## Eventual Responsibilities
- DOM tree extraction, filtering, and serialization
- Viewport coordinate mapping and bounding box geometry
- Screen capture utility helpers for browser tabs
- Browser environment detection and compatibility helpers (Chrome, Firefox)
- Safe DOM querying and element state inspection
