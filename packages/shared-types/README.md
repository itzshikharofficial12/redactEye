# Shared Types Package (`packages/shared-types`)

This package is reserved for data structures and interface definitions shared across the browser extension, local AI vision engine, local privacy engine, and the remote agent server.

## Contract Status
- **Status:** Interface definition reserved (not yet implemented).
- **Ownership:** Shared contract — modifications require discussion and consensus across all developers before updating.

Future types defined here will establish common models for:
- Screen capture metadata and viewport dimensions
- DOM representation and extracted element nodes
- Visual and text bounding boxes
- Sanitized context envelopes sent to the server
- System configuration and telemetry envelopes
