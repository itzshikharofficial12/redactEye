# Research Notes & Investigations

This directory serves as the central repository for all technical research notes, model evaluations, runtime benchmarks, library comparisons, and exploratory findings for RedactEye.

Future research documents will cover topics including:
- In-browser runtime performance (WebGPU, ONNX Runtime Web, Transformers.js)
- Browser screen capture mechanisms and performance
- PII detection methodologies and regex/NER heuristics
- OCR, face detection, and UI element detection model comparisons
- Cloud and local VLM reasoning comparisons
- Client-side redaction and masking techniques
